# Iterative / 原 Plan 方块抓取：实验室快捷入口

保存的是 trial_04 的成功配置：操作者反馈「Yes this is perfect!」。这是当前
UR5 CB3 + RH56 右手（只写、不读）+ 固定 D435 + 40 mm 蓝色方块的人工确认结果，
不是自动成功检测，也不是重复试验成功率或碰撞安全认证。

## 怎么运行

在仓库目录打开终端。先验证离线入口（不连接任何硬件）：

```bash
.venv312/bin/python tools/run_iterative_cube.py
```

它使用 trial_04 的保存图像。图像预览不代表当前方块位置；实机运行总会重新拍照。
准备好后运行一轮：

```bash
.venv312/bin/python tools/run_iterative_cube.py --execute
```

阅读终端注意事项，确认物体已支撑、路径畅通且同意所列执行条件后，**按一次 Enter** 开始。
输入任何非空内容、Ctrl-C 或关闭输入都会在连接硬件前取消。不要通过管道预先输入换行。
`--help` 查看参数；可用 `--out artifacts/iterative_cube_runs/my_trial` 指定新目录，
已有目录不会覆盖。离线模式可以用 `--capture <保存的RGB-D目录>` 更换输入。

## 每轮准备与结束

1. 把方块可靠放回桌面，确保手中没有悬空物体。**上一轮抬起后不能直接再跑，
   否则开头张手会使方块掉落。** 处理物体时机械臂应停止，遵循实验室安全流程。
2. 检查安装未变、目标区只有待抓的蓝色方块；张手、退离、回扫描位、抓取和抬升
   路径畅通，人员退出运动区。全程观察并准备急停。
3. 脚本先张手；若处于允许的低位，则在固定 XY/姿态下垂直退至扫描高度
   （最多 150 mm），再到保存的扫描位。不需要每轮手动摆机械臂，但不支持任意起点。
4. 新拍三帧并检测 → 原 Plan 的接近及手腕跟随闭合 → 垂直抬升 50 mm → 保持。
   无额外抓取悬停点，无自动放置、松手、重试或无限循环。
5. 若触发保护、目标检测失败或路径检查拒绝，停止并检查原因；不要增大限制绕过。
   软件退出不能替代急停，手可能仍保持最后指令。

若报 `Unexpected segment length/rotation`，先看 `summary.json` 中的
`preflight_segments`，不要当成浮点误差直接忽略。2026-09-09 的
`20260909T202015_539047Z` 运行在扫描位到接近点的检查中测得 300.873 mm，
超过 300 mm 上限；上一轮为 293.715 mm。本次检测目标相对上一轮变化约
`[+4.84, −7.40, +1.15] mm`，并非手指指令或姿态发生改变。
该轮已张手并回扫描位，但未开始抓取。之后按操作者明确要求，本快捷入口设置
`max_scan_to_approach_mm: null`，取消的仅是**扫描位到原 Plan 接近点**的固定距离上限。
没有增加中间点，也没有修改目标、手指指令或 planner 轨迹。仍检查工作空间、旋转、
控制器安全状态、整段采样 IK 和关节连续性；路径距离仍记录，`limit_mm` 为 `null`。
回扫描位的 300 mm、低位退离的 150 mm、闭合步长限制和抬升距离限制均保留。
UR5 保护功能不能保证检测全部手指/桌面/物体碰撞；取消此上限不构成安全认证。

## 保存了什么

独立配置：`configs/ur5_iterative_cube_lab.yaml`。不改变原 planner、控制器或模型。

| 参数 | 本次基线 |
| --- | --- |
| 实物宽/高 | 40 / 40 mm |
| 内部目标宽度 | 40 + 10 − 2 = 48 mm |
| 闭合余量 | 总间隙减少 2 mm，不是每根手指 2 mm |
| 抓取位置偏移 | UR 基座坐标 [0, −5, 0] mm，不是工具局部轴 |
| 原始力寄存器 | 1000，不代表实测接触力 |
| 速度 | 原 planner：机械臂 0.1 m/s、0.2 m/s²；手 speed=1000 |
| 抓取深度 / yaw / 抬升 | 顶面下 10 mm / 90° / 基座 +Z 50 mm |

手没有反馈：等待时间不等于确认手指接触，成功仍需目视判断。
48 mm 内部宽度预测的 38 mm 指间隙未被独立实测。−Y 5 mm 是此姿态的经验位置补偿，
不是新的相机外参，也不能直接泛化到 GGX 的任意姿态。

每轮自动保存到 `artifacts/iterative_cube_runs/<UTC时间>/`：`summary.csv`、
`summary.json`、`plan.json`，实机另存照片、检测、机械臂轨迹和原始串口 TX/RX。
`launcher.json` 记录基线及执行授权。命令完成仍标记抓取未验证；人工判断另行记录。
trial_04 的人工成功反馈保存在其 `operator_observation.json`，没有修改机器原始结论。

`configs/ur5_iterative_cube_baseline.json` 校验独立配置、五个标定/起点文件及关键源码。
文件缺失或变化会阻止启动；先核对变化，不要只更新校验值绕过检查。它不是完整
软件环境锁或文件备份，无法检测相机、桌面或手被碰动。物理安装有变化必须重新验证。
换电脑时需要另行备份 manifest 列出的本地 artifacts 和预览 capture；这些不进 Git。
本次只保存本地文件，没有提交或推送。
