# Not Now

These tasks are deferred until the RH56 read/write issue is resolved or the
paper-v2 reproducibility and parameter-justification work is complete.

- Vision integration.
- Real H1-2 manipulation.
- Standing policy.
- FAME or MPC.
- Spray-bottle, mouse, bottle-cap, or other new dexterous demos.
- Full high-level ROS2 port.
- Custom board design, unless direct USB-RS485 works and the intermediate board
  path clearly fails.

Deferred work can still be tracked as issues, but it should not block the
simulation-only paper-v2 evidence path.
